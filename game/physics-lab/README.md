# PHYSICS LAB

近未来の物理研究施設を舞台にした、ブラウザ完結型の3D物理アクション・パズルゲーム。
企画・実装仕様は `PHYSICS_LAB_SPEC.md`、AI向け指示は `AGENT_INSTRUCTIONS.md` を参照。

## 現在の状態: Phase 2 実装済み（2026-11-19）

Phase 1（基本物理環境）と Phase 2（操作とゲーム基盤）を実装済み。Phase 3 以降は未着手。

### Phase 1 で実装したもの
- Three.js 初期化（レンダラー、シーン、フォグ、ライティング、シャドウ）
- Rapier 3D 初期化、固定 60Hz タイムステップ（蓄積＋ステップ上限でタブ復帰時の暴走防止）
- 研究施設風テストルーム: グリッド床、ガラス壁＋発光トリム、段差ステップ、スロープ、円柱、ブロック
- 球体プレイヤー: Dynamic RigidBody + 球 Collider、CCD 有効、重力・摩擦・反発
- 移動: WASD / 矢印キー（カメラ基準、速度ステアリング、水平速度上限 8 m/s、空中操作は弱く）
- ジャンプ: Space（接地判定は下向きレイキャスト、二段ジャンプ不可）
- 三人称カメラ: 補間追従、マウス視点（Pointer Lock 基本、未対応時はドラッグで代替）、仰角クランプ、床めり込み防止（最低高さ）
- ウィンドウリサイズ対応

### Phase 2 で実装したもの
- ブースト: Shift。ゲージ制（最大100、消費 40/秒＝全開約2.5秒、回復 22/秒・遅延0.7秒）。
  ブースト中は最高速 13 m/s、球の帯が明るくなる。押し続けてもゲージが尽きたら回復しない
  （離すと回復開始）。右下にゲージ表示
- チェックポイント: 4か所（スタート / 北エリア / ステップ上段 / 南東エリア）。
  範囲内に入ると有効化され色がシアン→ゴールドに変わり、通知が出る。
  高さ判定あり（高所CPの真下では誤認しない）。左上に進捗（CHECKPOINT n / 4）
- リスポーン: R キー。最後のチェックポイントへ戻り、位置・向きを復元、
  線速度・角速度・回転をリセット、カメラも再同期。回数を数えて右上に表示
- 落下判定: y < -10 で自動リスポーン（現ルームは囲われているため通常は発生しない。
  ステージ制になる Phase 4 以降で本領）
- ポーズ: Esc / P、または Pointer Lock が外れたとき自動でポーズ。
  ポーズ中は物理・タイマーが止まり、移動入力は無効。メニューから再開 /
  チェックポイントから再開ができる
- HUD: 左上=ステージ・チェックポイント進捗、右上=タイム（ポーズ中は停止）と
  リスポーン回数、右下=ブーストゲージ、左下=操作ガイド、中央=通知。
  デバッグ表示（位置・速度・接地・ゲージ・状態）も継続

## 操作方法
| 操作 | キー |
|---|---|
| 移動 | W A S D / 矢印キー（カメラ基準） |
| ジャンプ | Space（接地中のみ） |
| ブースト | Shift（押している間、ゲージ消費） |
| リスポーン | R（最後のチェックポイントへ） |
| ポーズ | Esc / P（Pointer Lock 解除でもポーズ） |
| 視点 | クリックで Pointer Lock → マウス移動。ロックできない環境ではドラッグ |

## 起動方法

### そのまま開く（配信形式）
`index.html` を静的ホスティングに置けばそのまま動く。依存ライブラリは
importmap 経由でバージョン固定 CDN（jsDelivr）から読み込むため、ビルド不要。
公開パスは `site/game/physics-lab/`（GitHub Pages では `https://camelliab1.com/game/physics-lab/`）。
※ ローカルで `file://` で開くと ES Modules の CORS 制約で動かない。簡易サーバー経由で開くこと。

### ローカル開発（Vite）
```
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的ビルド（base: './' でサブパス配信対応）
npm run test:physics  # Phase 1 物理テスト（Node、描画なし）
npm run test:phase2   # Phase 2 テスト（Node、描画なし）
```

## 技術構成
- Three.js 0.180.0 / @dimforge/rapier3d-compat 0.21.0 / Vite 8.3.8（すべてバージョン固定）
- 配信は site リポジトリの既存ルール（ビルドなし静的ファイル、他ゲームと同方式）に合わせ、
  ソースをそのまま置き、ライブラリは CDN から読む。
  Vite ビルドも可能だが、Rapier 同梱で JS が約 4.8MB になるため、
  MCP の 1ファイル 1MB 制限に収まるソース＋CDN 形式を正としている。

## 既知の課題・次のフェーズへの申し送り
- カメラの壁めり込み対策は最低高さクランプのみ（Raycast による距離補正は未実装）。
- Pointer Lock 中の Esc はブラウザ仕様で keydown が届かないため、ロック解除を
  検知してポーズする方式。Chrome ではロック解除直後の再ロックにクールダウンがあり、
  再開直後にロックが拒否されることがある（その場合は画面クリックで再ロック可能）。
- スロープ上の接地・移動感、Pointer Lock の実機確認は未実施。
- ジャンプ最高点は約 3.5m。ステップ上段CP（1.9m）へはジャンプで直接届く。
