# ポピュラス風ゲーム（発展シミュレーション版）

Muse の静的アーティファクト（slug: popiyurasufeng-gemushi-zuo）で開発中の試作を、単一HTMLファイルとして書き出して保存したもの。

## 開き方
`index.html` をブラウザで開くだけで遊べる（外部読み込みなし、単一ファイル）。

## ゲーム内容（2026-11-18 時点）
- 整地（高さ）と対戦を廃止した、地形種類ベースの平和な発展シミュレーション
- 地形：平野・農地・森・水・山の5種類タイル（45×45）。山と水は侵入不可。スタート地形はランダム生成（平野 約58〜69%、森 20〜29%、水 5〜11%、山 3〜6%。開始地点の周囲9×9の平野と近くの池・森を保証）
- 神の操作は地形変更のみ（マナ制）：平野⇔森 6、水⇔陸 10、山は作る25・崩す35
- 村人：建物から生まれ、出生地の周囲で農民・土木に自動分化。歩く人は人口の1/8まで（超過分は合体して強くなる）
- 農民：水辺の平野を農地化、灌漑（農地に隣接し水から3マス以内の平野を農地化、水辺より遅い）、建物に隣接する森を伐採しながら直接開墾して農地化
- 土木：開墾と橋かけ
- 森：伐採すると茶色い伐採地（切り株つき）になり、約50秒で森に再生
- 農地：建物に隣接しているものだけが備蓄できる。上限は建物ごとに 小屋2マス・家4マス・豪邸8マス・お城16マス。隣接農地が上限まで揃うと建物が成長し上限も増える。備蓄先を失った農地は平野に戻る
- 食料：人口維持にも消費され、余れば出生、尽きると村が痩せる
- 建物：小屋→家→豪邸→お城の4段階
- 表示：全体表示／3倍表示の切替、90°回転（Q/E/R・ボタン）
- 「資源の推移」パネル：食料・木材・人口・農地の折れ線グラフ（2秒ごとに記録）
- 敵・勝敗・武士は未実装（後から敵を入れる可能性あり）

## 3Dプロトタイプ（2026-11-18 追加）
- `prototype-3d.html` は、現行2D版を残したまま3D表現を検証する独立プロトタイプ。
- Three.js（jsDelivr CDN）を使用。初回表示にはインターネット接続が必要。
- 45×45の地形、起伏、湖、森、岩山、集落、住民、雲、ライティングと影を立体表示する。
- マウスドラッグで回転、右ドラッグで平行移動、ホイールでズーム。ダブルクリックまたは「村を見る」で初期視点へ戻る。
- 「自動回転」で観察、「時間：進行」で住民の移動と人口・集落数の簡易な時間変化を確認できる。
- 現段階は描画・カメラの技術検証用。既存2D版の人口・農業・資源ロジックとは未接続で、表示上の人口・集落増加も仮の演出。
- 次の段階では、3D表示とシミュレーション状態を分離し、現在の2D版から地形・集落データを移せる共通データ構造を設計する。文明進化・対戦・観察モードはその上に追加する。


## 3Dプロトタイプの構成（2026-11-18 更新）
- `prototype-3d.html`: 画面構造とUI。CSS・JavaScriptは別ファイル。
- `prototype-3d.css`: HUD、操作ボタン、レスポンシブ表示。
- `prototype-3d.js`: Three.jsによる地形・水面・植生・建物・住民・カメラ描画。
- Three.js は jsDelivr CDN（v0.180.0）から読み込む。初回表示にはインターネット接続が必要。
- 描画を改善し、ブロック状の地面を連続した起伏地形へ変更。頂点カラー、湖・蛇行する川、海面、広葉樹・針葉樹、岩、畑、土の小道、切妻屋根の家屋、窓・煙突、柔らかい霧と影を追加。
- 地形・植生・岩はインスタンシングを利用し、ブラウザでの描画負荷を抑える。
- Q/Eキーで90度回転。従来のドラッグ・右ドラッグ・ホイール操作も継続。
- 人口や集落数の増加は引き続き仮演出で、2D版のシミュレーションとは未接続。今回の目的は世界のアート方向性を確認すること。


## 建物カタログ（2026-11-18 更新）
- 建物モデルは `prototype-3d-buildings.js` に分離。地形描画やカメラ制御とは独立して追加・変更できる。
- 住宅に加え、農家・穀物倉庫・工房・風車・集会所・礼拝堂・見張り塔を配置。
- 建物ごとに屋根形状・壁材・基礎・窓・扉・煙突などを変え、用途が遠景でも見分けやすいシルエットにする。
- 風車の羽根は時間進行中に回転する。
