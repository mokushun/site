## 開き方
`index.html` をブラウザで開くだけで遊べる（外部読み込みなし、単一ファイル）。

## ゲーム内容（2026-11-18 時点）
- 整地（高さ）と対戦を廃止した、地形種類ベースの平和な発展シミュレーション
- 地形：平野・農地・森・水・山の5種類タイル（45×45）。山と水は侵入不可。スタート地形はランダム生成（平野 約58〜69%、森 20〜29%、水 5〜11%、山 3〜6%。開始地点の周囲9×9の平野と近くの池・森を保証）
- 神の操作は地形変更のみ（マナ制）：平野⇔森 6、水⇔陸 10、山は作る25・崩す35
- 村人：建物から生まれ、出生地の周囲で農民・土木に自動分化。歩く人は人口の1/8まで（超過分は合体して強くなる）
- 農民：水辺の平野を農地化、灌漑（農地に隣接し水から3マス以内の平野を農地化、水辺より遅い）、建物に隣接する森を伐採しながら直接開墾して農地化
- 土木：開墾と橋かけ
- 森：伐採すると茶色い伐採地（切り株つき）になり、約50秒で森に再生
- 農地：建物に隣接しているものだけが備蓄できる。上限は建物ごとに 小屋2マス・家4マス・豪邸8マス・お城16マス。隣接農地が上限まで揃うと建物が成長し上限も増える。備蓄先を失った農地は平野に戻る
- 食料：人口維持にも消費され、余れば出生、尽きると村が痩せる
- 建物：小屋→家→豪邸→お城の4段階
- 表示：全体表示／3倍表示の切替、90°回転（Q/E/R・ボタン）
- 「資源の推移」パネル：食料・木材・人口・農地の折れ線グラフ（2秒ごとに記録）
- 敵・勝敗・武士は未実装（後から敵を入れる可能性あり）

## 3D文明シミュレーション：初期介入機能（2026-11-19）
- 「土地を肥沃に」: ツールを選択して地面をクリックすると、クリック地点の周囲の肥沃度・水分が上昇する。地表色にも反映。
- 「雨を降らせる」: 一定時間、雨粒を表示し、全域の土壌水分と肥沃度を少しずつ上げる。
- 農地は肥沃度に応じて食料を生産。人口維持のために食料を消費し、余剰があれば人口が増え、不足すると減少する。
- 文明は建物のない土地と住民1人から開始。建物カタログ側の初期村（住宅・農家・広場・記念碑・畑・道）も撤去し、建物はシミュレーションで新設されたものだけを表示する。最初の住民は採集で食料をつなぎ、最初の農地を作り、食料に余裕ができると住居を建てる。住居ができてから人口が増える。
- 住民の表示人数をシミュレーション人口に連動。最大100体の住民モデルを用意し、人口に合わせて表示・非表示を切り替える。時間進行中は表示中の住民だけが歩く。100人を超える人口は現段階では表示上限に達する。
- 農地の作物は5秒ごとのシミュレーション更新で肥沃度に応じて背が伸びる。肥沃な畑ほど作物が大きく、痩せた畑ほど低く見える。
- 自動建設される住宅・農地は、最初の5秒間は木組みの足場だけを表示し、その後に完成した建物・畑が現れる。初期配置の建物は完成状態で開始する。
- 住民は円運動を廃止し、農地・建設現場・住宅を目的地にした往復ルートを歩く。最初の住民は採集地点と農地を往復し、2人目は建設現場や農地を手伝う。到着後は作業のために立ち止まる簡易表現。次の課題は、採集・耕作・資材運搬・建設の手作業アニメーションと、作業に応じた道具・姿勢の表現。
- シミュレーションは時間進行中のみ進む。時間停止中は雨・食料生産・人口変化も停止。


## 3D文明の生活・出生・資源循環（2026-11-19）
- 人口増加は住宅単位で管理。1軒につき最大3人が暮らし、出生した住民は該当する家の玄関付近から登場する。住宅が満員になり、食料・木材・農地の余力がある場合に新しい住宅を建てる。
- 住宅建設には食料と木材が必要。農地は人口5人あたり1か所を目安に増やし、農業生産力が足りない場合は人口・住宅の拡大を抑える。
- 木材は森林作業によって蓄積する簡易モデル。住民は農作業・伐採・建築・運搬の役割に分かれ、農作業では前かがみと腕の動き、伐採では斧を振る動作を行う。
- HUDに木材量を追加。出生時に家の位置から住民モデルを出現させる。
- 現段階の伐採は資源量を時間で増やす抽象化で、樹木メッシュの実際の切り倒し・切り株への置換や木材束の運搬は未実装。次の改善候補。


## 農地の立地条件・水源（2026-11-19）
- 農地候補は地形の傾斜を周囲4方向の標高差から判定し、傾斜が小さい平地に限定する。
- 森林の樹木位置と岩の位置を保持し、樹木から2.5ワールド単位以内、岩から1.8以内の場所は農地候補から除外する。水域そのものも除外する。
- 湖岸・川岸から0.8〜8.5程度の距離にある平地を候補にし、水源に近く、より平坦で肥沃な場所を優先する。
- 水源に近い農地は食料生産に小さなボーナスが付く。雨による土壌水分の変化は既存の肥沃度・水分システムで継続する。
- 現段階は水源との距離による簡易評価。用水路や実際の灌漑設備は未実装。

## 3Dグラフィックスのリアル化（2026-11-21、GRAPHICS_TASK.md ステップ0〜2）
- 品質プリセット: URL の `?quality=low|high`（既定は high）と、画面の「画質」ボタンで切り替える（切替時は再読み込み）。low は従来同等以下の負荷（影 2048、pixelRatio 上限 1.25、地形テクスチャなし）。high は全機能（影 4096、地形テクスチャあり）。
- ステップ1（空と光）: 単色背景を Three.js addons の Sky に変更。空を PMREM で環境マップ化して `scene.environment` に設定し、陰の側にも空の色が回るようにした。霧の色を地平線の色に合わせ、ACES の露出を 1.0 に調整。
- ステップ2（地形）: Canvas のバリューノイズから、草・土・岩・湿った砂の4種の色テクスチャと、凹凸（bump）用のノイズを手続き生成。地形マテリアルを `onBeforeCompile` で拡張し、高さ・傾斜・水際の近さで混合する（急斜面は岩、水際の低地は湿った砂、平地は草に土の斑）。近景と遠景の2スケールで重ね、元の頂点カラーは弱い色づけとして残した。high のみ有効。
- 実装前の見た目の特徴（ステップ0の記録）: 地形は頂点カラーのみでテクスチャなし。空は単色背景で環境光（IBL）なし。水は単色マテリアル。木は球と円錐、岩は十二面体のまま。草・花などの細部なし。時間による光の変化なし。
- ステップ3（水）: 湖・川のマテリアルに、Canvas で生成したタイリング可能な法線マップ（正弦波の合成→Sobel変換）を付け、毎フレーム UV をスクロールして水面が動くようにした。反射はステップ1の環境マップを使用。湖の岸の泡は、水面そのもののシェーダで縁を白くする方式（別面を置かないので岸から浮かない。2026-11-21 にユーザー指摘を受けてリング面方式から変更）。遠景の海も同じ法線マップ（大スケール）で色と反射を調整。川の泡は未実装（法線と反射のみ）。すべて high のみで、low は従来の単色マテリアル。
- 湖面の欠け対策（2026-11-21）: 湖の水位計算で参照する円周と実際の水面メッシュの半径が異なっていたため、斜面では地形に水面が切られて半月状に見える場合があった。実際の水面半径（湖沼半径の0.97倍）に合わせて円周128点の最低地形高を測り、水位をその少し下に設定。水面の円周分割も48から128へ増やした。地形や水域判定は変更していない。
- ステップ4（植生と岩）: 広葉樹の樹冠を、ノイズで歪めた球4個の合成に変更し、インスタンスごとに色と大きさにばらつきを付けた。針葉樹は円錐3段重ね。樹冠は風でわずかに揺れる（シェーダ、high のみ）。岩は頂点をノイズで変位させた不規則な形にし、少し地中に埋めた。草の房（交差した板＋Canvas の草テクスチャ）、低木、花（茎＋色つきの頭）をインスタンスで散布。水・急斜面・村の中心は避けた。木と岩の配置そのもの（農地判定が使う座標）は変更していない。
- ステップ5（建物と住民）: 建物の壁（漆喰）・木・屋根瓦・石に Canvas 生成の質感を付けた（形・配置は無変更）。住民は服に織り目テクスチャ、体の比率を微調整。
- ステップ6（大気と時間）: WORLD TIME（08:00開始）と太陽・空・霧・光を連動（朝焼け・夕焼けの暖色、夜は月明かりの下限あり）。雲にまだら模様、遠くの鳥5羽、舞う塵240個を追加。ブルームは見送り（描画経路の差し替えリスク回避）。環境マップは開始時の空のまま。
- ステップ5 強化（2026-11-22）: 画面に出る家・農地は simulation.js が建てるため、そちらの壁・屋根・木・畑の土にも濃い質感＋bump を適用（畑は畝の縞）。住民は麦わら帽子／髪キャップで見分け可能にし、服に帯縞を追加。
- ステップ6 速度変更（2026-11-22）: WORLD TIME は 1秒=2分（1日≒12分）。その後さらに3倍速へ変更（2026-11-22）: 1秒=6分（1日≒4分）。速度の定義は utils.js の WORLD_MIN_PER_SEC に一本化され、大気と住民の昼夜が共有する。人口・食料・資材の進み（実秒ベース）は不変。
- ステップ7（性能と仕上げ、2026-11-22）: 品質プリセットの適用範囲を全機能で点検した。pixelRatio（high 1.8 / low 1.25）、影解像度（4096 / 2048）、地形テクスチャ・水の法線・樹冠の風揺れ（high のみ）、草・低木・花の散布密度（low で削減）、舞う塵（high 240個 / low 80個、今回追加で連動）。建物・住民の質感は小さな Canvas テクスチャのみで負荷が軽いため両プリセット共通とした。鳥（5羽）と太陽連動も負荷が軽微なため共通。
- 未実装のまま: 川の泡、ブルーム、環境マップの時刻連動更新。用水路・灌漑設備も未実装（水源距離による簡易評価のみ）。
- 未確認: 実機での fps（ヘッドレスのソフトウェア描画では high/low とも極端に遅く、相対比較しかできない。low の方が軽い構成であることはコード上で確認済み）。

## ゲーム性（GAMEPLAY_TASK、2026-11-22 実装）
- 畑ごとの肥沃度: 畑はそれぞれ肥沃度を持ち、収穫のたびに下がる（水辺に近い畑は減りが最大30%軽い）。自然回復はごくわずかで、放っておくと痩せて食料が減り、人口が減る。
- 収穫サイクル: 植え付け→成長→収穫を繰り返す。収穫量 = 基本量×(0.4+肥沃度)。調整値は simulation.js の TUNING に集約。
- 信仰心: 上限 40+住宅×8。食料に余裕があるときと収穫で増え、餓死で減る。HUD に数値とバーで表示。
- 恵みの雨（prototype-3d-miracle.js）: 信仰心10以上で雨雲を呼べる。雲はポインタに追従し、真下の畑と地面を潤す（消費 2/秒）。信仰心が尽きると雲は消える。無料の「土地を肥沃に」「雨を降らせる」は廃止。
- 作物の等級（prototype-3d-crops.js）: 肥沃度で 麦（〜0.6）→豆・野菜（0.6〜）→果樹（0.8〜）に変わる（植え直し時に判定、ヒステリシス付き）。土の色・ひび割れ・しおれ・縁の花・きらめきでも肥沃度が見分けられる。
- 畑をクリックすると情報パネル（作物・肥沃度・次の収穫まで・収穫量の目安）が出る。

## 地形と建設ルール（2026-11-22 追加）
- 地形は毎回ランダム: 湖3つの位置・大きさ、川の流れ、丘の位相を読み込みごとに抽選する（terrain.js）。中心のおおよそ半径5.5以内は常に陸で、川も中心を避ける。
- 中心の建築禁止は半径5→2.5に縮小（simulation.js の availableSpot）。家は中心に近い場所から建つので、村の中心が自然にできる。
- 開墾中と建設中は見た目で区別する: 畑の工事は木枠ではなく、耕した土の区画＋四隅の杭＋土の山（開墾中）。家の工事は従来どおり木の足場枠（建設中）。工事現場の情報には種別（farm/house）が付き、建築の住民は家の現場を優先する。

## 住民の振る舞い（2026-11-22、villagers.js）
- 職業は住民ごとに固定で、服の色と対応する: 橙=農民（麦わら帽子）、青=木こり、 黄=建築、緑=運搬。番号の4での余りで決まる。
- 昼（05:30-19:30）: 農民は畑で作業（畑が足りない住民は既存の畑の隣で開墾、畑が皆無なら中心周りの原野で開墾）、木こりは森の木元で伐採、建築は建築現場の周辺で作業（現場がなければ中心で待機）、運搬は森→建築現場（なければ中心）を往復し、荷ありの脚では丸太を抱える。
- 夜（19:30-05:30）: 全員が自分の家に帰り、家の中で寝る（非表示）。家がまだ無い住民は中心で待機する。
- 家として扱うのは完成した家だけ（2026-11-22 追加）: 建築中の家は帰宅先にも出生先にもならない。赤ちゃんは完成した家の玄関先に現れる。
- 建築時間は 5秒→25秒 に延長（simulation.js、家・農地とも）。
- 職業は見た目と動きの割り当てであり、シミュレーションの生産計算とは未連動（今後連動させる場合は simulation.js 側に個体管理が必要）。
